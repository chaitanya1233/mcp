# MCP Roadmap

This repository serves as a workspace and roadmap for building and experimenting with Model Context Protocol (MCP) servers and clients.

## Project Structure

- `devloper_mcp/`: Contains the core implementation of the MCP client and server components.
- `My_First_MCP/`: A submodule or subdirectory for initial MCP explorations.

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/chaitanya1233/mcp.git
    cd mcp
    ```

2.  **Setup Environment:**
    Navigate to the `devloper_mcp` directory and install the necessary requirements:
    ```bash
    cd devloper_mcp
    pip install -r requirements.txt
    ```
